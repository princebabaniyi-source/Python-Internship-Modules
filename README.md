## How to use this repo

- Each folder contains a module task and a starter Python file.
- You can open the module folder and complete the task there.
- To submit one module, share the link to that module's README or file in GitHub.

## Suggested submission format

- Module 01: `https://github.com/princebabaniyi-source/Python-Internship-Modules/tree/main/module_01`
- Module 02: `https://github.com/princebabaniyi-source/Python-Internship-Modules/tree/main/module_02`
- ...

Replace the module number to create a unique link for each task.
